# Full-Stack Web Application

A full-stack application built with React (Vite), Node.js, Express, MongoDB Atlas, and Google Gemini AI.

## 🚀 Live Links
- **Live Frontend Application:** `https://complete-frontend-xxxx.onrender.com`
- **Live Backend API Base URL:** `https://complete-backend-api.onrender.com`

## ✨ Features
- **Responsive UI**: Built with React and Vite for optimal performance.
- **RESTful API**: Node.js & Express backend handling core business logic and database operations.
- **AI Integration**: Integrated with Google GenAI / Gemini API.
- **Database Storage**: MongoDB Atlas cloud integration via Mongoose.
- **Production Secrets**: Full environment variable separation and CORS configuration across services.

## 🛠 Tech Stack
- **Frontend**: React.js, Vite, JavaScript, CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas
- **AI Service**: Google GenAI (Gemini)
- **Deployment**: Render (Static Site + Web Service)
